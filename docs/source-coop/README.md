# stac-geoparquet

Example [stac-geoparquet](https://stac-geoparquet.org/) datasets, intended for experiments, tutorials, and benchmarking.
These aren't updated on any regular cadence, so probably won't have the latest data.

## Datasets

| Prefix | Description |
| -- | -- |
| mspc-sentinel-2-l2a | Copied directly from the [Microsoft Planetary Computer](https://planetarycomputer.microsoft.com/docs/quickstarts/stac-geoparquet/) [Sentinel 2 collection](https://planetarycomputer.microsoft.com/dataset/sentinel-2-l2a) |
